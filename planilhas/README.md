# Pasta de planilhas (uso temporário)

Coloque **aqui** o arquivo `.xlsx` da pesquisa que você quer transformar em dashboard,
e aponte este caminho para a IA (Copilot). Exemplo: `planilhas/arraia-2026.xlsx`.

## ⚠️ Importante — privacidade

As planilhas da pesquisa contêm **dados pessoais** (nome, matrícula, celular, e-mail).

- Os arquivos de planilha desta pasta **NÃO são enviados ao GitHub** (estão no `.gitignore`).
- Depois de gerar o `dados.js` do evento, você pode **apagar** a planilha daqui — ela já
  cumpriu o papel, e o `dados.js` guarda só dados agregados e anonimizados.
- Só este `README.md` fica versionado; os `.xlsx` ficam apenas no seu computador.
